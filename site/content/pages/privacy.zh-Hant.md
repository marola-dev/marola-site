## 隱私

本頁說明你使用研究頁面、聯絡表單與地圖時，marola 保存了什麼。內容描述專案目前的做法，並非法律意見。團隊尚未核定最終的法律文本。

## marola 保存什麼

- **你的 GitHub 帳戶。** 當你登入以發布研究時，marola 會保存 GitHub 編號、帳號名稱與帳戶建立日期。只讀取你的公開資料。
- **你的研究。** 你輸入的文字（標題、作者、摘要、地區、主題、連結、授權條款、AI 聲明）、PDF 檔案、SHA-256 雜湊值與日期。研究會即刻公開，並附上你的 GitHub 帳號。
- **API 金鑰。** 只保存每把金鑰的雜湊值與日期。金鑰只顯示一次，不會保存。
- **工作階段。** 只保存工作階段的雜湊值，為期 12 小時。登入期間由一個 Cookie 保存工作階段。另一個短時 Cookie 只在登入期間的 10 分鐘內有效。沒有追蹤 Cookie。
- **檢舉。** 有人檢舉研究時: 該研究、時間與寫下的理由。沒有姓名、沒有地址、沒有帳戶。
- **聯絡表單。** 你在其中輸入的姓名、電子郵件與訊息。

## marola 不保存什麼

- 你的 GitHub 電子郵件。marola 不索取，也永遠看不到。
- 你的 IP 位址。伺服器日誌不保存位址。
- 你的 GitHub 權杖。只在伺服器上使用一次，隨即丟棄。
- 瀏覽器指紋，或任何關於你閱讀內容的側寫。

## 為什麼

為了標明研究的發布者、留下已發布內容與時間的公開紀錄、遏阻垃圾內容（GitHub 帳號的帳齡與各項限制使用資料庫中的值），並讓團隊能隱藏造成傷害的研究。

## 保存多久

- 帳戶資料: 直到你自己刪除帳戶。
- 工作階段: 12 小時。金鑰: 直到撤銷或刪除帳戶。
- 已發布的研究: 直到撤回或團隊隱藏。之後該列會以雜湊值、日期與理由保留為墓碑。這是已發布內容的公開紀錄。
- 聯絡訊息: 直到團隊回覆後刪除。
- 檢舉: 隨研究的列一同保存，直到團隊結案。舊紀錄何時刪除由團隊決定。

## 誰能看到

所有人都能看到公開研究中你的 GitHub 帳號與日期。所有人都能看到墓碑（id、雜湊值、日期、理由）。其餘部分只有團隊成員能在伺服器上看到: 檢舉與聯絡訊息。GitHub 知道你登入過 marola。地圖頁的底圖來自 marola 自己的伺服器，沒有任何地圖供應商會看到你的位址。只有在你開啟時，衛星圖層才會向 NASA 請求影像；只有在你開啟時，Spotify 播放器才會從 Spotify 載入。

## 你能做什麼

- 在[帳戶頁面](/account)**刪除帳戶**。這會刪除你的金鑰、工作階段與帳戶。你的研究立即下架，並以「作者刪除帳戶」的理由保留為墓碑。各列與檔案留在伺服器上但不提供。若要連檔案一併刪除，請向團隊提出，由團隊決定。墓碑無論如何都會保留。
- 在同一頁面**撤回一篇研究**。
- **請求下架**研究或研究中的姓名: 見[下架](/takedown.html)。
- 透過[聯絡表單](/contact.html)**詢問 marola 保存了你的什麼資料**，或要求更正。
